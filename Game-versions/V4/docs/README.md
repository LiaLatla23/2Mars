## Evidence and limitations

The repository contains source code, project documentation and an automated test bot. Team members also manually played complete game sessions. This is internal playtesting, not a formal study of learning outcomes with external participants.

Scientific facts, game-balance parameters and fictional content must remain clearly distinguished. Do not describe the game as using live NASA APIs, direct NASA planetary datasets or a high-fidelity orbital simulator.
