## 5. Use of Super Intelligence (SI) · borrador para el formulario (inglés)

> We used SI tools as follows. **Code:** the game code (GDScript, Godot 4.7), the asset scripts and the documentation were written with an AI coding assistant (Claude, Anthropic) and checked with an automated test bot that plays the real game. **3D and 2D art:** the rover, terrain, Mars globe and scenery are geometry generated by that code; part and rock pictures are renders of those models. **Audio:** music and sound effects were synthesised by a program (no samples, no AI audio model); the music files carry descriptive metadata. **Images and video:** The SpaceNuts and 2Mars logos were generated with ChatGPT. Game visuals were generated with Claude using the team's Canva style references. Higgsfield was used for the launch animation and additional rover animations. The team used Canva for visual direction, Claude and OpenAI Codex for coding assistance, and Microsoft Copilot to consolidate component spreadsheets. No generated content uses NASA logos, flags or mission identifiers.

## 6. Tools, coding languages, hardware and software (inglés)

> 2Mars was built with the Godot 4.7 engine (GL Compatibility renderer) and written in GDScript. The 3D rover, terrain, Mars globe and scenery are procedural geometry created in code. Python (NumPy, SciPy, Pillow) scripts synthesise the music and sound effects and prepare the icons, and FFmpeg converts audio to Ogg Vorbis and the launch clip to Ogg Theora. Fonts are Fredoka and Nunito (SIL Open Font License). AI coding assistants (Claude by Anthropic and OpenAI Codex) supported coding, debugging and iteration with us, and an automated bot plays full missions in English and Spanish as a regression test. The game runs on a standard Windows, macOS or Linux PC with keyboard and mouse; no special hardware is required.

No special hardware was required; the game was developed and tested on the team's computers. Add exact computer specifications only if the team wants to disclose them.

## 7. Explicación científica breve para jueces (inglés)

> 2Mars turns Mars 2020 Perseverance mission documentation into decisions with consequences. NASA's four science objectives become four campaign zones. The seven real instruments keep their real roles: PIXL and SHERLOC need the arm, and each instrument only returns its own kind of evidence. Communications follow NASA's description of the rover's links: a fast UHF relay that works only while an orbiter is overhead, and a slow direct X-band link, so science counts only once Earth receives it. Power is generation versus consumption in watts and watt-hours, with nights, dust and safe mode. Real events shape the game: the empty first sample tube at Roubion, the wheel redesign after Curiosity, and the signal delay that forces the rover to land itself. Game numbers (kilograms, credits, megabytes, rates and times) are a simplified educational model and are labelled as such next to the real figures. The game distinguishes habitability and possible biosignatures from confirmed evidence: NASA has not confirmed life on Mars.
