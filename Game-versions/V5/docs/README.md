## Reviewer reading path

1. Start with the [repository overview](../../../README.md).
2. Read the [V5.1 game guide](../README.md).
3. Review [challenge alignment](RUBRIC_MAPPING.md) and the [implementation map](REQUIREMENTS_CHECKLIST.md).
4. Follow [science traceability](SCIENCE_TRACEABILITY.md) and the [resource audit](RESOURCE_AUDIT.md).
5. Consult the [evidence index](../../../evidence/README.md) for educational design, walkthrough and testing notes.

## Scope

This documentation describes the source project in this folder. Archived V1, V3 and V4 documents are historical and should not be used as evidence for current V5 features unless explicitly identified as background.

The repository does not claim NASA endorsement, professional engineering validation, formal educational impact or a successful test run unless a dated result is recorded.
