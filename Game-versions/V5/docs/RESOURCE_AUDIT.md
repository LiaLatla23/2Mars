## Scientific references

The game and its Science Library reference NASA/JPL material concerning:

- Mars 2020 Perseverance science objectives and instruments.
- Rover components and engineering systems.
- Perseverance Mars rock samples.
- The first sample collection attempt.
- Mars rover communications and the Mars 2020 landing sequence.
- NASA mission stories and related rover context.

The detailed source list is maintained in [NASA_RESOURCES_USED.md](../../../research/NASA_RESOURCES_USED.md), while [SCIENCE_TRACEABILITY.md](SCIENCE_TRACEABILITY.md) explains how selected subjects connect to gameplay.

## Attribution and model boundaries

- NASA/JPL references are used as scientific and mission sources; the project is not affiliated with or endorsed by NASA.
- NASA material is not the same as a NASA dataset integrated into the game. 2Mars does not directly load NASA planetary datasets or live NASA APIs.
- Game-balance values are not NASA specifications. The source code separates the game catalogue and model parameters from selected real Perseverance facts.
- Generated visuals and video must be disclosed in accordance with the current event rules. The team's production-tool use is recorded in [AI and asset attribution](../../../evidence/AI_AND_ASSET_ATTRIBUTION.md).
- Third-party fonts retain their own license notices.

## Scope

This record summarizes team-confirmed production tools and the documented source project. It is not a forensic audit of every binary file or an independent legal certification of every asset.
