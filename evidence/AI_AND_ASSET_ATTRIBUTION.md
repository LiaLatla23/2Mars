## Technologies and project tools

- Godot Engine 4.7 and GDScript — game engine and implementation language.
- GitHub — source control and project documentation.
- Vercel — web-demo hosting.
- Fredoka and Nunito — fonts included in the game; font files include SIL Open Font License notices.
- Python utility scripts and FFmpeg — used in the documented asset/audio workflow.

## Attribution scope

The team directed, selected, reviewed and integrated generated assets into the project. AI tools did not independently design, validate or submit the entire game. This record is not a forensic audit of every binary asset.

The official Space Apps submission should disclose the tools and uses above accurately. Generated images and video must follow the event's current visible-marking rules. This file records tool provenance; it does not by itself prove that every exported image or video contains the required on-asset disclosure.

## NASA relationship

NASA/JPL materials are used as scientific and mission references. The project is not affiliated with or endorsed by NASA. Generated project assets do not claim to be official NASA imagery or branding.
