# AI and asset attribution · 2Mars

This record summarizes the production-tool information confirmed by Team SpaceNuts. It is intended to support transparent attribution in the repository and the official NASA Space Apps submission. It does not replace the event's current submission or SI rules; the team must verify those rules and any visible-marking requirements before final publication.

## Team-confirmed use

| Tool | Confirmed use |

## Other project tools and technologies

- Godot Engine 4.7 and GDScript: game engine and implementation language.
- GitHub: source control and project documentation.
- Vercel: web deployment at https://2mars.vercel.app/.
- Fredoka and Nunito: fonts included in V4; their font files include SIL Open Font License notices.
- Python-based utility scripts and FFmpeg are documented in the V4 resource audit and submission resources. Check the exact tool/library use against the current files before copying a complete tools list into an external form.

## Attribution and verification checklist

Before final submission or public release:

- [ ] Check the current NASA Space Apps SI policy for visible attribution/watermark requirements on generated images and video.
- [ ] Inspect the actual exported logo files and confirm that any required disclosure is present.
- [ ] Inspect each generated visual asset and exported animation; do not assume a source-tool disclosure alone satisfies an on-asset marking requirement.
- [ ] Confirm the exact attribution requirements for fonts and any third-party media.
- [ ] Ensure the submission's SI disclosure describes assistance accurately; do not imply that an AI tool independently developed the whole game.
- [ ] Keep team-created direction, selection, editing and integration distinct from AI-assisted generation.

## Scope

This file records tool use confirmed by the team. It is not a forensic audit of every binary file, and it does not assert that every asset has already passed the event's attribution requirements. See [V4 Resource Audit](../Game-versions/V4/docs/RESOURCE_AUDIT.md) for the detailed asset and compliance audit.
