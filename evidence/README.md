## Evidence standard

Claims are limited to features visible in V5 source, repository screenshots, reproducible test definitions, source references or team-confirmed production records. Internal playtesting is not external user research. Intended learning opportunities are not measured learning outcomes. Game abstractions are not NASA engineering specifications.
